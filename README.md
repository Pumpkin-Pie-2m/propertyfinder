# PropertyFinder

## Description
A frontend website for PropertyFinder - a real estate search and discovery platform designed to help users find their perfect property with ease.

## Features
- 🏠 Property search and filtering
- 📍 Location-based discovery
- 💰 Price comparison tools
- 📱 Fully responsive design
- 🎨 Modern, intuitive user interface
- ⚡ Fast loading and smooth interactions

## Technologies
- **HTML5** (87.3%) - Structure and markup
- **JavaScript** (6.6%) - Interactivity and dynamic features
- **CSS** (6.1%) - Styling and responsive design

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Pumpkin-Pie-2m/propertyfinder.git
   ```
2. Navigate into the directory:
   ```bash
   cd propertyfinder
   ```

## Usage
1. Open `index.html` in your web browser, or
2. Serve the project using a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

## Features in Detail

### Property Search
- Filter properties by location, price range, and property type
- View detailed information about each property
- Save favorite properties for later review

### User Interface
- Clean, modern design optimized for desktop and mobile
- Quick navigation between property listings
- Easy-to-use search filters
